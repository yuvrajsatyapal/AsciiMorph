Architecture: bounded decoder → cancellable worker → shared document → shared
renderer/export; transactional save ordering before Studio handoff.
Stack: existing Next.js App Router, strict TS, React, Zustand, Canvas, IndexedDB.
User explicitly authorized execution and independent review in this session.

1. [x] Baseline: run lint, typecheck, 52 tests, build and desktop/mobile browser

2. [x] Engine: write src/converter/engine.test.ts for luminance, tone, dimensions,
   density, color, transparency, Braille masks, filters, cancellation, bad inputs,
   JSON round trip. Run red. Implement engine.ts, presets.ts and settings.ts;
