# Shared style geometry and composition verification

The shared helpers are numerical building blocks for future Pixel, Mosaic, and Braille jobs. They do not register a style renderer or change the Studio readiness list.

`FrameGeometry::new` validates the closed style settings and source extent, then uses the same floor-left/top, ceil-right/bottom, crop-before-quarter-turn mapping as Characters. It does not choose a family grid. `AreaSampler` walks exact rectangle/pixel overlap one source pixel per work unit, discards out-of-bounds area, accumulates alpha-weighted RGB and independent alpha in `f64`, and returns unrounded values. A transparent pixel contributes no hidden RGB. Family jobs must apply their own cell dimensions, tone, and quantization.

`FrameComposer` accepts a painted full-frame RGBA layer by move. Each work unit performs one bilinear resize output, one blur output (at most 65 fixed initialization taps), or one source-over pixel. It calls the same extracted pure numerical primitives as `CompleteCharactersJob`: premultiplied original-source bilinear resize, two `f32` planes with `f64` moving sums, radii `[8S-1, 8S-1, 8S]` across six passes, and straight-alpha output. The blur is the already documented independent box approximation, with no browser parity claim.

Peak admission uses source capacity + `SourceImage` inline size + other session reservations + `FrameComposer` inline size + supplied layer capacity + two `f32[4]` scratch capacities + a future RGBA serialization copy. `new` also checks any actual excess scratch capacity once. The borrowed atlas is not charged here; its captured allocation belongs in the caller's `other` session reservation. The 268,435,456-byte native cap and source budget are unchanged.

Measured on this host (native vector capacities): a 1×1 source/layer has 4-byte source, 312-byte combined inline metadata, 4-byte layer, 32-byte scratch, and 4-byte future copy: **356 bytes** admitted; exactly 356 passes and 355 rejects. A 1000×1000 source/layer has 4,000,000-byte source, 312-byte metadata, 4,000,000-byte layer, 32,000,000-byte scratch, and 4,000,000-byte future copy: **44,000,312 bytes** admitted; immediate native live storage is **40,000,312 bytes**, with the remaining 4,000,000 reserved for serialization. No extra capacity was observed in these fixtures.

The tests cover 17×13 identity and quarter-turn crop geometry; 1× and 2× extent and initialized pixels; transparent saturated RGB, constant opaque and fully transparent sources; a frame smaller than the nominal font cell; partial/outside sample rectangles; unrounded 127.5 alpha; zero-work, identity cancellation, one-shot frame retrieval, and exact/one-byte-short admission. Existing Characters backdrop and reference integration suites pass unchanged. The cfg(test) diagnostic `FixtureJob` was not used for scaled output.

Independent Task5 review accepted spec and quality with no actionable findings. Parent verification passed all 107 native tests and rebuilt the actual release WASM. The eight wrapper/worker/service regression suites passed 124 tests against that binary (SHA256 `c3ed27e03dab3bcbc63f757ebc70a66ad3557f9ff88b0800e1ead0ca341b769f`). Normalized cell placement and partial-cell rasterization remain explicit first-family acceptance tests; these shared primitives do not select or paint a family grid.
