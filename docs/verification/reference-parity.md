# Reference parity acceptance ledger

Scope: the complete approved rebuild. A catalog label, prototype treatment or passing numerical test does not establish a finished renderer. Rows remain open until their implementation, interaction tests and visual fixtures pass.

## Evidence and current status

- Canonical static inventory:105 tiles /96 selectable modes /10 categories in `docs/research/ascii-magic/2026-10-20/catalog-inventory.json`. Mode parameters/defaults remain unknown where that artifact says so.
- Desktop prototype: design gate ACCEPT for Studio/Flow shell. Screenshots and design artifacts live in `.planning/design/screens/ascii-magic-rebuild/`. Production route is pending.
- Phone sheets: proposed adaptation verified locally; reference pointer-coarse mobile layout has not been captured.
- Rust core: packed contract, browser calibration and source/tone processing implemented and task-reviewed; matching/session/worker/integration acceptance still pending.
- Supplied GitHub library is a separate animated-piece library. Its audit and exact commit/license exceptions are in `github-library-audit.md`; no general editor parity follows from its availability.

## Completion rule

A mode or workflow closes only when its evidence is linked here. Registry readiness stays false until its renderer and controls pass. Full parity requires every canonical tile/mode and workflow row to close; unavailable third-party services must be reported explicitly, with the approved local-only boundary preserved.
