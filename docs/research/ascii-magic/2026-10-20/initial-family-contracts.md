# Initial renderer family contracts, version1

Status: **partial Task1**. All15 canonical modes have rows. Pixel, Mosaic and Braille have closed, independently authored numerical/payload designs; eleven new families remain blocked. Characters retains its existing context-v1 API. No new renderer is ready, and no reference-output parity is claimed.

The companion [JSON](initial-family-contracts.json) is normative for ordered payload types, offsets, baseline values, ranges, descriptor provenance, equations, fixtures and per-row gates. Packet payload offsets are relative to the112byte STY1 header; no padding. Unknown or extra keys, invalid enums/nonfinite values and unsupported active operations reject. Empty payloads on blocked rows mean unavailable, never a zero-parameter effect.

## Method and provenance

Read the complete initial-family plan and rebuild spec; reused parameter/catalog/character sampling, placement and tone records and the Oct24 initial-family observations. Checked four original bundle SHA256 values against stored files and inspected original renderer text only. No bundle was executed/imported and no implementation body was copied. New output/control uploads were not exercised; existing CUA captures establish only inherited Mixed→Block→Braille UI state. Contrast70/blur0 are inherited observations, not baseline defaults. The clipped1109×720 screenshot is no numerical oracle.

Source hashes and zero-based Unicode ranges (exclusive ends) are recorded in JSON. Reference branch anchors use original09wgr6f2vxer0.js. Existing local shared-backdrop sources also have hashes; these describe our implementation and do not prove reference equivalence.

## Fixed common baseline

Following the parent baseline ruling, every closed new profile uses brightness0 and contrast20 as construction defaults. Brightness and contrast remain adjustable across their frozen payload bounds; these defaults are not invariant context fields. The invariant context is bgMode blur,bgBlur8,bgOpacity100,source-over,coverage100,darkThreshold30,edgeEmphasis0 and inactive advanced operations. Backdrop uses the existing Characters independently specified sigma8*S approximation: premultiplied bilinear resize; separable box radii[8S−1,8S−1,8S], horizontal/vertical for each; edge clamp; f64 sums with f32 pass stores; source-over then straight-alpha byte output. Full equations, ordering and memory requirements are in each closed row. Task5 must extract/verify these primitives without changing Characters behavior.

The listed neutral contrast0 and transparent-layer fixtures isolate numerical stages. Contrast0 is also allowed for a complete-profile render: it changes tone to neutral while the complete profile still composes the invariant blur8/opacity100 backdrop. Transparent layers in isolation fixtures do not replace that backdrop. A constant128 source distinguishes Pixel153 from Mosaic128 while retaining the real baseline. Unsupported backdrop values or active effects/depth/lights/animation/masks/text/grading cannot be coerced or dropped. They cause capability errors. No adjustable backdrop UI is earned by this contract.

## Independent algorithms and meaningful differences

Pixel uses rational pitch0.6*fontSize×fontSize, ceil grid/full partial cells, alpha-safe exact area color sampling, affine tone and six-level channel quantization. It fills whole cells; the bounded reference instead samples centers and draws inset rectangles. Mosaic square/wide/tall samples the entire merged tile and fills sharp, gapless rectangles. The reference sparse-samples a base cell, skips odd base positions for wide/tall, and rounds/insets tiles. These differences are intentional independent version1 semantics and prohibit exact-output claims.

Braille subdivides each cell2×4, samples each subrectangle with alpha-safe area weighting and uses an absolute luminance threshold. Spatial bits are [[0,3],[1,4],[2,5],[6,7]]. Atlas selection is U+2800+mask with no coverage-sort/ramp matching; blank paints no glyph. The reference four-tap samples, normalized luminance and ordered thresholds differ. Inversion changes dot luminance while retaining source glyph color. Full-cell area average supplies color/alpha. Partial cells remain included; this differs from reference floor-grid behavior.

Fixtures pin transparent hiddenRGB exclusion, half-up rounding,17×13 partial cells,1×/2× source partitions, quantization boundaries, wide/tall averages, all8 single-dot masks,127/128 threshold boundary, blank/full atlas identities and fixed-backdrop alpha composition. Fixture expectations are mathematical and have not been executed against a renderer.
