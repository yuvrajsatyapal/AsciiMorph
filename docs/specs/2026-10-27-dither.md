## Independent numerical contract

Crop and quarter rotation use existing geometry. Pixel-size square cells use exact alpha-weighted source-area samples; partial cells use the clipped area. Fully transparent samples have canonical zero RGB and emit no diffusion error. Contrast is `(channel-127.5)*contrast/100+127.5`, with the existing f32/f64 boundaries explicitly pinned by fixtures. Keep this distinct from Characters contrast0 neutral. Preserve source alpha; palette alpha is opaque and never replaces source alpha.

Palette ties choose the first entry by squared RGB distance. Luminance mode chooses the nearest Rec.709 palette luminance, first-entry ties. Per-channel mode quantizes each channel against that channel's sorted unique palette values; output may combine channels into colors outside the palette, and the UI/docs must say so. Custom uses the same rules. `original` is a separately labeled local Source RGB332 quantizer (8 red ×8 green ×4 blue values spanning0..255), not a claimed reconstruction of reference null-palette semantics.

For ordered/pattern algorithms, `q=(rank+0.5)/rankCount` (or a continuous periodic threshold), and add `255*(q-threshold/100)` to preprocessed RGB before quantization. Blend final quantized RGB with the sampled preprocessed RGB by strength/100; strength0 bypasses contrast/quantization and returns the sampled original RGB/alpha. This zero-strength identity is a layer/sample contract: complete-frame background composition remains separately controlled. Quantize/clamp/round only at the documented stage. Source RGB hidden by zero alpha never influences samples/errors.

Bayer starts `[[0,2],[3,1]]`; recursive quadrant offsets0,2,3,1 produce exact2/4/8/16 rank permutations. Halftone uses an independently ranked periodic8×8 squared-distance field with row-major ties. Radial uses a periodic concentric distance threshold, explicitly different from ranked halftone. LinesH/V/D use periodic y/x/(x+y) phase; angle rotates pattern coordinates about the origin. White noise uses a seeded coordinate hash. Blue noise uses an independently generated fixed16×16 rank tile (toroidal farthest-point ranking, stable tie rule); include the generated fixture and a low-frequency DFT-energy test demonstrating suppression relative to the seeded white-noise fixture. Do not alias white noise or copy the reference tile.

Diffusion runs left-to-right/top-to-bottom, clipping unavailable neighbors without renormalizing. Retain only current plus two future error rows. Floyd weights: `(1,0)7/16,(-1,1)3/16,(0,1)5/16,(1,1)1/16`. Atkinson: `(1,0),(2,0),(-1,1),(0,1),(1,1),(0,2)` each1/8. Stucki: forward row8,4; next row2,4,8,4,2; following row1,2,4,2,1, all/42. SierraLite: `(1,0)1/2,(-1,1)1/4,(0,1)1/4`. Standard diffuses RGB error; luminance diffuses scalar Rec.709 error equally across channels; perChannel diffuses independently. Error addressed to a transparent cell is discarded there and never propagated. Tests pin precision, threshold bias and strength/error ordering before registration.

If animation is enabled later: integer phase `floor(timeUs*speed/1_000_000)` translates ordered/pattern coordinates by the selected signed direction vector. Diffusion has no translating matrix: reject animated diffusion until a distinct documented behavior is implemented. Shimmer remains rejected until its deterministic rule has fixtures.
