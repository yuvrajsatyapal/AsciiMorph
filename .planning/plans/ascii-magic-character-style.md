## Scope, evidence and engineering rulings

- This is the ordinary nonrandom font-glyph `characters` branch for a specified input image. It is not all character controls, mixed/Braille/bitmap styles, Flow, animated media, masks/text/effects or full reference parity. Those unsupported project features must produce an explicit adapter limitation, not disappear.
- Four project parameters remain exactly `fontSize` 3..80/default11, `charSet` unique printable graphemes/default`@#S08Xx+=-;:. `, `brightness` -100..100/default0, `contrast` -100..100/default20. UI step1 does not silently quantize imported finite font sizes. Keep schema validation separate from render capability.
- `fontSize` controls geometry/font pixels, never inferred from grid dimensions: at render scale S, cell height=F*S and width=.6*F*S; frame dimensions derive from oriented cropped source times S. Characters uses floor grid dimensions, retaining partial-cell margins. Seed/time do not alter this static profile.
- Fixed context V1: mode characters, darkThreshold30, edgeEmphasis0/no edge field, coverage100, charOpacity100, invert=false, randomChars=false, blend=source-over, depth/lights/animation disabled, no glyph bloom/chroma/bitmap substitution, no grading/overlay/levels/curves/post-effects/text/masks. Ordinary glyph offsets0, scale1. These are an explicit versioned baseline; no undeclared render parameters enter project maps. Changing the context requires a new context/defaults version.
- Source pixels are browser-decoded, EXIF-oriented sRGB with straight alpha. Original reference upstream image preparation/color management/resizing/alpha treatment is unproved. **Parent alpha ruling:** alpha0 samples do not contribute to normalization or draw; partial alpha passes through to glyph opacity, using straight RGB for luminance/tone. Hidden RGB at alpha0 cannot affect output. This is independent transparent behavior, not observed reference alpha parity.
- Reference backdrop baseline is bgMode blur/bgBlur8/bgOpacity100/bgSolidColor#000000. A transparent glyph layer is only an intermediate. Complete-look binding waits for the separately reviewed Rust backdrop/composition task below; black CSS is not rendered blur. Parent approves independently specified alpha-safe Gaussian approximation/edge policy, with reference pixel equivalence still unproved.
- Reference top baseline is proved; effective inherited text alignment is not. **Parent placement ruling:** opt-in top/start with explicit LTR direction for this first profile. Keep old center/middle behavior. Overhang is retained through a shared measured atlas extent and origin wrapper, clipped only by the final frame, not each cell.
- **Parent font ruling:** a controlled `reference-system-monospace` policy intentionally uses exactly `"Courier New", Courier, monospace`; actual masks are measured in that browser and identified as stack+rasterization, never guaranteed installed Courier. This policy is distinct from arbitrary caller fallback strings. Named custom/test fonts still require a matching loaded registered FontFace; generic/controlled-system policies do not weaken that check.
- **Unicode/color policy:** Input ramp indices represent unique Unicode graphemes, preserving combining/emoji sequences as a single calibrated entry. This is an independent policy compared with the captured ordinary string/code-unit indexing. Masks retain measured alpha and are tinted with sampled/tone-adjusted RGB; native color-font/emoji RGB is not preserved and no color-emoji parity is claimed. Only an exact literal U+0020 entry is ordinary space; a different glyph with zero measured coverage is not space.

## Exact first-profile algorithm for independently authored fixtures

1. Independently specify crop pixels as floor(left/top) and ceil(right/bottom), clipped to source, then quarter-turn rotation via inverse integer-coordinate lookup; no full transformed source copy is required. This is an engineering crop preparation rule, not proved reference upstream preparation. Derive frameWidth/Height by round(orientedCropDimension*S), minimum1. S is explicitly 1/2/3/4; preview initially renders S1 and scales only its view.
2. Columns=floor(frameWidth/(.6*F*S)), rows=floor(frameHeight/(F*S)). Zero rows or columns produce an empty transparent glyph layer with `grid:null`; never invent one cell. Positive grids still cap at60,000. Source-center lookup divides by explicit S (equivalently the exact source-frame scale), not sourceWidth/gridColumns; partial margins make those different.
3. Range-probe stride=max(1,floor(min(rows,columns)/40)). Probe row/column indices starting0 at that stride; sample the floored cell centers mapped into prepared image coordinates. Luma=.299R+.587G+.114B; alpha0 excluded by independent policy. If no eligible probe exists, use range0..0. Span=max-min, with zero replaced by1. Each rendered cell center is sampled separately; normalized M=clamp((luma-min)/span,0,1).
4. At fixed darkThreshold30/edge0, ordinary non-special-mode darkness cutoff is `.6*(1-.30)=.42`: skip M<.42. Input ramp order is preserved. Index=min(N-1,floor((1-M)*N)), not coverage matching or sorting. A selected ordinary space produces no glyph. Range probe/dark threshold/cell selection anchors: cached common chunk `[101545,101831)`, `[105221,106019)`, `[108170,108300)`, `[113635,113945)`; check exact enclosing statements before coding.
5. Compute RGB after normalized-luminance selection using K(c)=259(c+255)/(255(259-c)); channel=clamp(K*(channel-128)+128+2.55*brightness,0,255). Contrast0 is neutral; baseline20 is not. Under this proved fixed-input branch, brightness/contrast alter color rather than glyph selection. Round output bytes explicitly to nearest integer; source alpha governs cell opacity under the independent rule. Do not remap into legacy contrast/gamma/density/coverage settings.
6. Composite actual measured input-order glyph masks at column*cellWidth/row*cellHeight plus shared atlas origin, preserving overhang. Use pixel-center inverse mapping with bilinear interpolation of mask alpha; alpha outside the finite mask is zero, not edge-clamped. Do not round logical positions/origins to integers. Apply tinted RGB and interpolated alpha with cell opacity, then row-major source-over composition so overlapping glyphs have a deterministic order. Alpha0/skipped/literal-space use the packed transparent sentinel when a grid is returned; a selected non-space zero-coverage glyph retains its index/cell opacity even though it paints no pixels. Full-frame margins survive. This interpolation is an independent raster policy: normalized browser fixtures assess agreement, without claiming exact fillText subpixel hinting.

## Additive versioned interfaces (preserve old entry points)

```ts
type ReferenceCharacterAtlasV1 = {
  version: 1; calibration: GlyphCalibrationV1;
  originX: number; originY: number;
  placement: "top-start-ltr"; ordering: "input";
  fontPolicy: "reference-system-monospace" | "verified-family";
};
type ReferenceCharactersSettingsV1 = {
  version: 1; frameWidth: number; frameHeight: number;
  fontSize: number; renderScale: 1 | 2 | 3 | 4;
  brightness: number; contrast: number; crop: NormalizedCrop;
  rotation: 0 | 90 | 180 | 270; backdrop: "none" | "solid" | "blur";
};
type ReferenceCharactersFrameV1 = {
  version: 1; width: number; height: number;
  rgba: Uint8Array; grid: PackedGlyphGrid | null;
};
```

Profile/context fixes blur8, black solid and opacity100; alternate backdrop variants are typed backend/test contexts, not extra project keys or exposed controls. Adapter always selects baseline blur. Frame metadata and all source/job/revision/calibration identities are validated before paint; RGBA is the final Rust-composited frame. A glyph-only intermediate is separately labeled unavailable as a complete look.

Proposed additive ABI: `render_characters_profile_version()->1` and `render_begin_characters_v1(handle,ptr,len)`. A112-byte staged block has eight u32 `[v,frameW,frameH,rotation,glyphCount,backdropKind,solidRGB,spaceIndexOr65535]`, then ten f64 `[F,S,brightness,contrast,cropX,cropY,cropW,cropH,originX,originY]`; backdropKind0/1/2. TS derives the exact ordinary-space index from input-order `calibration.glyphs.indexOf(" ")`, encoding65535 when absent. Rust accepts only65535 or an integer index<glyphCount and skips only that selected index; it has no strings and must never infer space from coverage/mask emptiness. Require glyphCount/current atlas identity agreement and validate origins/extents. Existing calibration upload transports masks/count/dimensions; retain those dimensions in Rust, with new atlas metadata validated at begin. No layout/flag reinterpretation of the old160-byte block.

New profile jobs use the same retained-source/session bounds but a typed job variant. Existing step/cancel/release can dispatch by that variant; old `takeGrid` refuses a profile job. New profile result header: eight u32 `[v,frameW,frameH,columns,rows,rgbaOffset,gridOffsetOr0,totalBytes]`, followed by checked aligned full-frame RGBA and optional existing packed-grid block. Keep exact header/offset/truncation/overflow tests independent of encoders. Optional export detection fails visibly on an old WASM module; do not fall through to legacy area sampling. Old ABI/version1 consumers remain compatible.

## Task 4: Separately review Rust backdrop and final composition

- [ ] Specify None=transparent, Solid=opaque black, Blur=resized original source with opacity100, using the same oriented crop/full-frame dimensions. This is a documented independent approximation, not proved reference upstream/browser blur.
- [ ] Use three separable sliding-box passes approximating Gaussian sigma=8*S.
