# AsciiMorph reference rebuild design configuration

Approved direction: reproduce the observed ASCII Magic Studio and Flow shell with AsciiMorph identity. This replaces the legacy amber direction. Source: docs/research/ascii-magic/2026-10-20/desktop-measurements.json and screenshots. Reconstruct independently; reference bundles and demo art are research only.

## Brand foundation
- Canvas #000000; panel #0a0a0a; raised control #111111; node #171717.
- Selected surface rgba(255,255,255,.04), measured on workspace/category active buttons in desktop-measurements.json.
- Text #f5f5f5; secondary rgba(245,245,245,.62); muted rgba(245,245,245,.42).
- Borders rgba(255,255,255,.10); active border #f5f5f5; card selection #f5f5f5 (reference selected card85%/active85% vary by state); favorite icon opacity .85 and toolbar icon opacity .92.
- Neutral hover #1a1a1a; black overlays rgba(0,0,0,.53) and rgba(0,0,0,.67).
- Accessibility departure: essential inactive tabs, placeholders, output values and section labels use secondary62%; reference muted42% reserved for nonessential metadata. Mobile tap targets expand to >=44px; mobile layout remains provisional.
- Sans: Satoshi, system-ui fallback. Fontshare CSS used for prototype; production licensing/self-host decision remains open.
- Mono: ui-monospace, SFMono-Regular, Menlo, Consolas.
- Square controls; 1px borders; 12px controls and 13px labels; 16px shell padding.
- Desktop navbar 52px; catalog 320px; dock 340px including 54px rail; floating actions 568×50px, 22px from bottom.
- Personality: precise, restrained, quiet; no amber, decorative gradients, marketing cards or large radii.

## Interaction and motion
Hover surfaces #1a1a1a; high-contrast keyboard focus. 120ms state transitions, 160ms panels. Reduced-motion disables motion. Catalog entry reveal only on initial load; continuous editor controls remain immediate.

## Reference and responsive limits
Desktop reconstructed from measured public signed-out UI. Reference pointer-coarse mobile route not captured; mobile sheets are explicitly proposed, not verified parity.
